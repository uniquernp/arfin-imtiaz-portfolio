# Arfin Imtiaz Portfolio

A static, responsive professional portfolio website.

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload all files in this folder.
3. In Vercel, import the GitHub repository.
4. Deploy. No build command is required.

The CV is included at `assets/Arfin_Imtiaz_CV.pdf`.
